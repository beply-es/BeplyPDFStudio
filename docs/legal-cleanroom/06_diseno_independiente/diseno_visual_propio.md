# Diseño visual propio

No se replica el layout exacto ni la estética de la referencia. Se define identidad propia.

## Tokens visuales Beply (por defecto)
- Paleta por defecto por diseño (definida en cada layout): primario, secundario, terciario,
  texto. Editables por el usuario.
- Tipografía: familias soportadas por el motor del core (helvetica/times/courier y, si está
  disponible, DejaVuSans para Unicode).
- Espaciados/márgenes con valores por defecto propios.

## 5 diseños propios (concebidos por caso de uso, no por imitación)
1. **Beply Classic** — limpio y sobrio; cabecera con logo + datos empresa; tabla clara; pie legal.
2. **Beply Modern** — bloques diferenciados; uso destacado del color corporativo.
3. **Beply Compact** — optimizado para muchas líneas; tipografía e interlineado reducidos.
4. **Beply Advisory** — asesorías; datos fiscales claros y texto legal destacado.
5. **Beply Ecommerce** — pedidos/albaranes; referencia/SKU, cantidades, observaciones de envío.

## UI de configuración
- Organización y textos propios; no se clona la disposición de la referencia.
- Agrupación por secciones propias: Página, Marca, Tipografía, Datos, Líneas, Textos, Avanzado.
