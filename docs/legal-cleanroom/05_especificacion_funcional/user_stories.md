# Historias de usuario

Formato: *Como [rol], quiero [acción], para [beneficio].*

## Administrador
- Como administrador, quiero elegir un diseño base y ajustar logo, colores y tipografía,
  para que los PDF reflejen la imagen de la empresa.
- Como administrador, quiero mostrar u ocultar datos del documento (cliente, agente,
  vencimientos…), para adaptar el PDF a cada necesidad.
- Como administrador, quiero definir las columnas de las líneas y su formato, para mostrar
  solo la información relevante.

## Usuario de facturación
- Como usuario de facturación, quiero que al imprimir una factura se aplique el diseño
  configurado, para emitir documentos coherentes sin pasos extra.
- Como usuario de facturación, quiero previsualizar el diseño, para validar antes de enviar.

## Asesoría / multiempresa
- Como asesoría, quiero formatos distintos por empresa y serie, para respetar la identidad
  de cada cliente.
- Como gestor multiempresa, quiero asignar plantillas por tipo de documento y serie, para
  diferenciar facturas, rectificativas, proformas, etc.

## Cliente con branding
- Como cliente con marca, quiero configurar logo (posición/tamaño), colores y textos
  legales/agradecimiento, para personalizar la comunicación.

## Soporte Beply
- Como soporte, quiero validar la configuración antes de guardar, para evitar PDF rotos.
- Como soporte, quiero un texto de pie con numeración de páginas, para documentos largos.
